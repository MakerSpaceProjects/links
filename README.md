# MakerSpace Projects – Links

Linkseite von MakerSpace Projects: https://makerspaceprojects.github.io/links/

Eine einzelne `index.html` – keine Abhängigkeiten, kein Build-Schritt.

## Links eintragen
In `index.html` bei jedem Eintrag `href="#"` durch die echte URL ersetzen.
Einträge mit `href="#"` erscheinen ausgegraut mit „bald“; ihr Icon in der Social-Leiste oben bleibt ausgeblendet.
Patreon und Etsy stehen sowohl in der Social-Leiste oben als auch als Karte – beide Stellen anpassen.

## Logo
`logo.jpg` (480 × 480 px) wird oben auf der Seite und als Vorschaubild beim Teilen genutzt,
`favicon.png` als Symbol im Browser-Tab. Zum Austauschen einfach die Dateien mit gleichem Namen ersetzen.
